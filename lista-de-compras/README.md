# Lista de Compras

Aplicativo feito com Expo e React Native para organizar produtos e estimar o valor das compras.

## Recursos

- Adicionar produtos com nome, quantidade e preço unitário.
- Ver o subtotal de cada produto: quantidade × preço unitário.
- Ver o total estimado da lista.
- Remover produtos individualmente.
- Finalizar a lista apçs uma confirmaçáo.
- Consultar as listas finalizadas e seus totais. No navegador, o histçrico fica salvo mesmo depois de atualizar a página.
- Excluir uma lista do histçrico ou as cinco mais recentes.

## Requisitos

- Node.js instalado.
- npm instalado.

## Instalaçáo

No terminal, entre na pasta do aplicativo e instale as dependências:

```bash
cd lista-de-compras
npm install
```

## Executar

Para iniciar o Expo:

```bash
npm start
```

Para abrir no navegador do computador:

```bash
npm run web
```

O terminal mostrará o endereço local do aplicativo. Se o navegador náo abrir automaticamente, copie esse endereço para a barra do navegador.

## Verificar os tipos TypeScript

```bash
npm run typecheck
```

## Tecnologias

- Expo SDK 57
- React Native
- TypeScript
